## Part 1: the code

### Major 1: a restart that stops after the lease moves is never finished
`factory/mods/tasks/bin/herdr_task/lease.py:299-305` and `:336`.

- **How it happens:** `restart()` claims the lease for the new coordinator (299), then re-parents (303), then ends the old one (304). The return code of `hc kill old` is ignored and `reparent` is not guarded, so a failed kill, an `OSError` or a killed tick leaves the old coordinator live with the lease already moved.
- **Why no later tick repairs it:** line 336 moves held news only when the previous holder is not live, and `orphans()` (286) counts a live parent as fine. Nothing ever ends a replaced holder; it is only listed under `not_coordinator`.
- **Result:** two live coordinators, both told they are the Assistant. Workers stay parented to the stuck one. `news.held_pass` (news.py:505-548) delivers the held news to the stuck one, or drops it at 508-510 once that one ends.
- **The stale-shell path has the same hole:** `lease.py:360-368`, added in 6e965f3a.
- **Fixture to run:** in `LeaseCase`, live `c1` holds the lease, worker `w1` has parent `c1`, `held["c1"]` has one item. Patch `lease.reparent` to raise, call `lease.restart(self.repo, c1)`, then `reconcile_pass` three times. Expected: `c1` and `n1` both live, `held["c1"]` unmoved, `w1` still on `c1`.

### Major 2: identity is by bare address outside `_live()`
`factory/mods/tasks/bin/herdr_task/revive.py:176-179` and `:286`.

- **How it happens:** `coordinator_addresses()` returns lease addresses with no `created_ms` check, and `watched()` and `plan()` use it. A later terminal at a dead holder's address is treated as the Assistant.
- **Result:** for a bare shell there, `plan()` returns `("fresh", <assistant template command>)` and revive types a coordinator into someone else's terminal, while reconcile starts the real one.

### The structural change
About 40–45 engine lines, which is why this is FIX and not REDESIGN. No round raised a major against the lease as identity.

1. `claim` replaces `previous` with a `retired` list of `{address, created_ms}` (about 4 lines).
2. One idempotent `finish()` runs every tick for the live holder: for each retired entry, move workers and held news, end it if `_live(entry)`, and drop the entry once it is gone and nothing is held for it. It replaces lines 335-339 and the kill tails in `restart` and `reconcile_pass` (about 14 lines, net fewer).
3. Stamp `starts` and a `starting: {name, at}` record before `hc run`; the next tick claims or ends a live terminal of that name that is not the holder (about 16 lines).
4. `revive.coordinator_addresses()` uses `live_holders()` (2 lines).
