Engine v2 state machines

The engine stores records of what happened and reads facts about the world. For each task it walks one ordered table from the top and stops at the first row that fits. That row says what to make sure of and who the task is waiting on. Nothing is remembered as a phase, so nothing can be stuck in one, and anything the acceptance table does not allow is refused.

Design draft of 2026-11-18, form B, revised after the first review. The tables have been read and audited, not run.
