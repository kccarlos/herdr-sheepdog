# Architecture

This is a short orientation for the code **as built at `main`**. The
design it implements is partly superseded: the agreed target
(investigations, blocked → blocked, no mid-sentence interruption, the
names shepherd / dog / flock) is in [`docs/roles.md`](roles.md) and the decisions and
order of work in [`docs/issues-2026-09-18.md`](issues-2026-09-18.md).
Where this page and `roles.md` differ, `roles.md` is the intent and this
page is what runs today. [`sheepdog-v1-plan.md`](../sheepdog-v1-plan.md)
is the original plan, kept for history.

## Diagram (plan §2)

```
┌─────────────────────────────────────────────────────────────┐
│  Browser  /voice   (mic → 16 kHz PCM → WS)  (WS → 24 kHz PCM → speaker)
│           /debug   (conversation view, SSE tail of the event log, fake-event buttons)
└───────────────┬─────────────────────────────────────────────┘
                │ WebSocket (audio bytes + a few control JSON msgs)
┌───────────────▼─────────────────────────────────────────────┐
│  sheepdog daemon (Go, single binary)                         │
│                                                              │
│   VoiceSession ──── Gemini 3.8 Live (WebSocket, owned here)  │
│        │ 2 tools + push                                      │
│   Supervisor ── state table ── event log (JSONL) ── SSE      │
│        │  │           │                                      │
│        │  └─ brain (Gemini or DeepSeek + tools, transcript)  │
│   herdr client   prompt parser (code, no model)              │
│   (unix socket)  CLI query tool (codex exec / claude -p,     │
│        │          read-only, timeout)                        │
└────────┼─────────────────────────────────────────────────────┘
         │ ~/.config/herdr/herdr.sock
   herdr ── worker agents (Codex / Claude Code / … in panes)
```

Three layers, hard boundaries (plan §2):

| Layer | Owns | Never does |
|---|---|---|
| Voice model (Gemini 3.8 Live) | hearing, speaking, turn-taking, judging the *moment*; two tools — `to_supervisor(text)` relays the shepherd's words verbatim, `stop()` runs the stop procedure | classify intent, name an agent, touch herdr, hold task state, plan multi-step work (docs/roles.md "One decision-maker") |
| Supervisor (daemon) | state table, pending action, event routing, tool implementations, all model calls that are not voice; its brain (`internal/brain`, [`docs/roles.md`](roles.md)) reasons over the transcript with tools behind `ask`/`propose` | speak; bypass a worker's approval gate (the one rail: `send_keys` only on the CEO's words, from the prompt's option set) |
| Workers (herdr panes) | actually changing code; their own approval prompts | — |

The Gemini session lives in the daemon, not the browser; the browser is
a dumb audio pipe. herdr feeds the daemon over its unix socket
subscription; `POST /api/herdr/event` is a second way in for the same
`herdr.Watcher` (another process, or `/debug`), not something herdr
needs configuring for.

## Package map

| Package | Owns |
|---|---|
| `cmd/sheepdog` | Flags, subcommands (`serve`, `config`, `herdr watch`, `voice-test`, `brain-test`, `prompts`, `eval`, `version`), wiring into `internal/app`. |
| `internal/app` | Assembles the daemon: config → event log → state store → herdr client + `Watcher` (or `internal/inject`'s mock) → brain (`--brain`, one provider per key: `gemini` over the pool, `deepseek` over `DEEPSEEK_API_KEY`, starting on `brain.provider`; `--brain=fake` wires two `braintest.Reflex` providers `fake`/`fake2`, dev-only scripted models with no network call) → supervisor → voice session (or a no-op pusher with `--voice=off`) → web server; owns the run/shutdown lifecycle. |
| `internal/config` | Loads `~/.config/sheepdog/config.toml` + `SHEEPDOG_*` env overrides + `--env-file`; `config show`/`config init` support. See [`CONFIG.md`](../CONFIG.md). |
| `internal/herdr` | The herdr unix socket client and the `Watcher` that turns its event streams into deduplicated, debounced `Transition`s. See [`docs/herdr-protocol.md`](herdr-protocol.md). |
| `internal/state` | The persisted state table: per-pane rows (alias, kind, workspace, state, state_since, current task, last block), the single-slot pending action, session bookkeeping; atomic JSON persistence with a debounced hardware-durable fsync option. |
| `internal/eventlog` | The append-only JSONL event log every component writes to (decision D10): one file per UTC day, an in-memory ring for late subscribers, SSE fan-out. |
| `internal/prose` | The plain-text helpers the model-facing code shares: what goes into a window (`TailBytes`, `TruncateRunes`), what comes out (`ExtractJSON`), and the D9 scrubber (`Spoken`). |
| `internal/cli` | The read-only CLI query tool: detects codex/claude on `PATH` and runs one non-interactively and read-only, for the brain's `run_cli` lookups and for a background investigation. It captures the sub-agent's own session id (codex's `thread.started`, claude's `session_id`) and can resume it for a follow-up (`Query.Session`, the `*_resume_cmd` templates). See [`docs/cli-query-tools.md`](cli-query-tools.md). |
| `internal/supervisor` | The daemon's coordinator: pure Go logic over the herdr client, the state table, the parsed prompt and the voice session's push channel — the only component that touches herdr (decision D1). It handles the voice's two tools (`utterance.go`, `stop.go`): `to_supervisor` runs the code fast paths — a bare answer to the one open prompt, a bare stop word — and then one `utterance` brain turn over the shepherd's verbatim words; `stop` runs the stop procedure. It owns the pending-action lifecycle (decision D3) and is the brain's `Host` (roster, ledger, reads, `prompt`/`send_keys`/`interrupt`/`promise`/`note` over the same pending paths), answering from the roster on `ErrFallback`; it runs the brain's `announce` turn on every block/finish, speaks the one line that event gets and applies the chattiness ceiling to the brain's judgment (`announce.go`, [`docs/roles.md`](roles.md) "Pushes"); and it owns the investigation jobs the brain's `investigate` tool starts (`investigate.go`: one live job per agent, the ledger in `session.investigations`, the `KindInvestigation` delivery turn, cancellation from the stop procedure) — the same seam as promises, since the roster, the workspace, the state file and the push are all here. |
| `internal/brain` | The SVP (plan D7-revised, [`docs/roles.md`](roles.md)): a stateful agent loop over a function-calling model behind the `Model` seam — `GenaiModel` (`genai` `GenerateContent`, key pool rotating on 429) and `OpenAICompatModel` (DeepSeek's chat completions over plain `net/http`: tools as JSON Schema, tool calls with the API's ids, usage and finish reason mapped, HTTP errors verbatim; it implements `MessageModel`, so the loop hands it the window's messages and it replays DeepSeek's `reasoning_content` from `Message.Raw` for the messages the same provider and model produced) — registered per provider id, the pair `(provider, model)` snapshotted per turn and switchable between turns (`SetModel`, `Models` per provider); with `read_screen` / `run_cli` / `list_agents` / `recall` and the actions `prompt` / `send_keys` / `interrupt`; the one rail in the `send_keys` executor; provenance delimiters around worker output; one JSONL transcript per run under `<data_dir>/brain/`; the `ContextEngine` seam (ingest / assemble / compact / afterTurn, the memory plug point) with a default engine that prunes tool results to stubs and compacts the oldest half into a summary; two-priority turn serialisation (event turns yield to a waiting CEO turn and coalesce per agent); a sectioned system prompt from `prompts/svp/{SOUL,RULES}.md`. `braintest` holds the scripted model and in-memory host for tests. |
| `internal/voice` | The model-agnostic `VoiceSession` contract (plan §3.7); `internal/voice/gemini` implements it for Gemini Live (session resumption, context compression, key rotation), `internal/voice/wav` and `internal/voice/wsproto` are its audio/framing helpers, `internal/voice/echotools` is a test double. |
| `internal/web` | The HTTP surface on `web.bind:web.port` (`127.0.0.1` by default; a non-loopback bind needs `web.token`, docs/ws-contract.md "Auth"): `/voice` and `/debug` (embedded static pages, public), `GET /api/hello` (public: name/version/voice name, whether a token is needed, the `/ws` audio format), `POST /api/login` (public: trades a correct token for the `sheepdog_token` cookie), `/events` (SSE), the audio+control WebSocket, and the small JSON API (state — its `pending_action` carries `agent`, `summary`, `question`, `command` and `options[{index, label, keys, default}]` — inject, `/api/herdr/event`; `POST /api/pending/answer {id, option}` — answer the open question by tap, a shepherd input through the same rail and executor, 409 `{"error":"that question is no longer open"}` for a stale id; `GET /api/brain/transcript?since=<seq>&n=` — the brain's transcript from its in-memory store, one `seq` per message, `GET /api/brain/context` — the seqs in the model's window with pruned stubs, estimated tokens vs `window_tokens`, the last compaction and the prompt sections' sizes and sources, `GET /api/brain/system_prompt` — the assembled sections with text, `GET /api/brain/models[?provider=<id>][&refresh=1]` — the discovered model catalog of the current or named provider (Gemini's model list filtered to `generateContent`, `recommended` for the text models; DeepSeek's `GET /models`, all recommended; cached 10 minutes per provider; a failed fetch keeps the last list and sets `error`) with the current `provider`/`model` and every provider in `providers[]`, unavailable ones with the `reason`, `PUT /api/brain/model {provider, model}` — the runtime switch (400 with the reason for a provider without a key), persisted in `session.brain_provider` / `session.brain_model`; all five 503 with the reason when the brain is off). In `--dev` mode `/testdata/<name>.wav` and `/testdata/brain/<name>.jsonl` serve the fixtures. |
| `internal/inject` | The debug-only fake event path: lets `/debug` (and tests) drive the whole supervisor chain without a real herdr or a microphone. |
| `internal/logging` | The tiny structured-event `Logger` interface every component logs through. |
| `web/voice`, `web/debug` | Vanilla JS + AudioWorklet pages served by `internal/web`; `web/debug/conversation.js` is the pure event→chat grouping behind the Conversation tab, `web/debug/swimlane.js` the event→lanes/arrows/chains layout behind the Swimlane tab, both over `web/debug/grouping.js` (tool call/result pairing generic over any `<prefix>.tool_call`/`<prefix>.tool_result` family, fragments, dividers), and `web/debug/supervisor.js` the transcript+context→items and context→meter-segments logic behind the Supervisor tab (window marker placement, tool pairing by id, turn headers from `brain.turn`, compaction cards); `web/debug/dom.js` holds the shared DOM helpers (raw-JSON block, expand/collapse state, follow-scroll). All `node --test`. |
| `prompts/` | The embedded prompt workspace: the voice's `assistant.md`, the shepherd's `USER.md` and the brain's `svp/{SOUL,RULES}.md`, with the override `Loader`. |

## Event types

Every `logging.Logger.Log(source, type, paneID, payload)` call's `type`,
grepped from the source (`grep -rhoE '"[a-z_]+\.[a-z_]+"' internal cmd`)
and grouped by source. This is decision D10's ground truth; `/debug` is
only a viewer of it.

- **brain**: `brain.turn` (`trigger` ceo\|event, `kind` ask\|propose, `provider`, `model`, `steps`, `model_calls`, `dur_ms`, `fallback`, `tokens_in`, `tokens_out`, `window_tokens`, `acted`), `brain.step` (one model call: `step`, `provider`, `model`, `dur_ms`, `prompt_tokens`, `completion_tokens`, `reasoning_tokens` when the provider reports them, `function_calls` names, `tool_calls` count, `forced` when answer-only, `template` = kind), `brain.tool_call` / `brain.tool_result` (paired by `id`; `name`, `args` / `dur_ms`, `result` truncated to 1 KB, `error`), `brain.rail_blocked` (a refused `send_keys`, or any action tool named in an event turn: `agent`, `keys`, `trigger`, `reason`), `brain.compaction` (`before_tokens`, `after_tokens`, `dropped`; its summary call is not counted in `brain.turn.model_calls`), `brain.fallback` (`reason`: timeout, step_budget, model_error, rate_limited, bad_reply, queue_timeout, cancelled; `acted`), `brain.system_prompt` (once per run: `sections` with `chars`, `total_chars`, `provider`, `model`), `brain.rate_limited` (`provider` for DeepSeek, `key_index`, `keys`, `retry_after_ms`), `brain.transcript` (one per message appended to the run's transcript: `seq`, `kind`, `turn` — the Supervisor tab's cue to fetch `/api/brain/transcript?since=`; the message itself is not in the event), `brain.transcript_error`, `brain.yielded` (an event turn stopped before a model call because a CEO turn was waiting: `turn`, `kind`, `agent`, `event`, `step`, `steps_done`, `ceo_waiting`; followed by `brain.fallback {reason: yielded}`), `brain.event_coalesced` (a newer event turn about the same agent replaced a queued one: `agent`, `event`, `kind`; the replaced turn logs `brain.fallback {reason: coalesced}`), `brain.model_changed` (the runtime switch: `from_provider`, `from`, `provider`, `to`, `via` debug\|state; a `system` transcript message marks it), `brain.catalog` / `brain.catalog_error` (a model-list fetch: `provider`, `models` count or `error`, `refresh`, `cached`). `brain.turn.kind` is ask\|propose\|utterance\|stop for CEO turns and announce\|investigation for event turns (`trigger` event); `brain.tool_call.name` may be `promise`, `note` or `investigate`. `brain.fallback.reason` adds yielded and coalesced. Logged by the supervisor (source supervisor): `brain.push_decision` (one per announce judgment: `via` brain\|template\|ceiling (skipped before any turn), `urgency_requested` interrupt\|idle\|silent\|skip\|"", `urgency_applied`, `ceiling` = the chattiness level, `reason` brain\|ceiling\|promise\|promise_due\|stale\|late\|wait\|timeout\|fallback\|yielded\|coalesced, `late`, `agent`, `event`, `template` (the code sentence), `spoken`, `detail`, `relates_to`, `needs_user`, `kept` ids, `keeps_promise_ids`), `brain.push_late` (a brain line that arrived after the code sentence was spoken and was dropped: `turn`, `dur_ms`, `spoken`, `needs_user`, `added`), `brain.push_stale` (a line about a prompt that is no longer open: `turn`, `pending`, `spoken`)
- **cli**: `cli.detected`, `cli.run` (`backend`, `cmd`, `exit`, `dur_ms`, `output`, `killed`, `capped`, `session` — whether the backend reported one, never the id itself — and `resumed`)
- **investigation** (logged by the supervisor, source supervisor): `investigation.started` (`id`, `agent`, `source` cli\|worker, `backend`, `question`, `follow_up_of`, `resumed`), `investigation.done` (`id`, `agent`, `backend`, `dur_ms`, `bytes`, `session_id_present`), `investigation.cancelled` (`id`, `agent`, `reason` superseded\|stop\|shutdown, `dur_ms`), `investigation.error` (`id`, `agent`, `dur_ms`, `error`). The answer is delivered by a `brain.turn {kind: investigation, trigger: event}` whose line is pushed `idle` as `voice.push {answers_job}`.
- **daemon**: `daemon.start` (`brain` on\|off\|fake, `brain_provider`, `brain_model` — the live pair, the configured one until a switch was restored), `daemon.stop`, `daemon.brain_model_error` (the state file's `session.brain_provider` / `brain_model` was rejected: `provider`, `model`, `error`), `daemon.cli_error`, `daemon.drain_timeout`, `daemon.herdr_unavailable`, `daemon.voice_error`, `daemon.web_error`
- **eventlog**: `eventlog.subscriber_dropped`
- **herdr**: `herdr.state`, `herdr.transition`, `herdr.debounce_cancelled`, `herdr.dedup`, `herdr.fleet`, `herdr.list_error`, `herdr.read`, `herdr.send`, `herdr.snapshot_error`
- **supervisor**: `note.created`, `promise.created` (`id`, `text`, `agent`, `event`, `turn`, `due`), `promise.kept` (`id`, `text`, `agent`, `event`, `spoken`, `urgency`, `via` brain\|template, `chattiness`), `promise.expired` (`id`, `age_s`), `promise.cancelled` (`id`, `reason`), `promise.carried_over` (`ids`: promises made before this daemon run, announced once at startup as "Still watching for: …" and flagged so the briefing trailer and any later restart never repeat them), `pending.cancelled`, `pending.confirmed` (`id`, `answer`, `keys`, `via` brain\|fast_path\|confirm\|tap, `option` for a tap), `pending.created` (`id`, `kind`, `agent`, `summary`, `question`, `command`, `options` — `[{index, label, keys, default}]` — `yes_keys`, `no_keys`, `expires_at`), `pending.expired`, `pending.replaced`, `pending.revived`, `supervisor.ask_error`, `supervisor.block_error`, `supervisor.blocked_no_question`, `supervisor.briefing_repeat` (a `KindUtterance` request's roster sentence was byte-identical to the one last delivered within `supervisor.repeat_window_s`: `roster`, `age_s`), `supervisor.cancel_error`, `supervisor.confirm_error`, `supervisor.done_error`, `supervisor.done_question`, `supervisor.finished_suppressed`, `supervisor.note_error`, `supervisor.propose_error`, `supervisor.push_error`, `supervisor.push_quiet` (a push the chattiness level suppressed), `supervisor.push_skipped`, `supervisor.query_error`, `supervisor.reconcile_error`, `supervisor.reprompt` (a synthetic `blocked → blocked` transition raised: `after_ms`, `question`, `source` reprompt\|reconcile), `supervisor.reprompt_poll` (the post-answer poll ended: `polls`, `outcome` raised\|left_blocked\|same_prompt\|timeout), `supervisor.settings` (chattiness changed at runtime), `supervisor.state_error`, `supervisor.echo_ignored` (`text`: a relay of a push just spoken), `supervisor.voice_initiative_ignored` (`text`: a `to_supervisor` call with no shepherd input — transcript, typed text or tap — since the previous call and the last spoken push; nothing runs, docs/roles.md "The one rail"), `brain.rail_blocked` (also logged by the supervisor for the fast path and a tap: `agent`, `keys`, `trigger` fast_path\|tap, `reason`, `id`)
- **voice**: `voice.closed`, `voice.connect`, `voice.connect_error`, `voice.disconnected`, `voice.drop`, `voice.event_dropped`, `voice.goaway`, `voice.handle_dropped`, `voice.interrupted`, `voice.key_rotated`, `voice.muted`, `voice.push` (now carries `scheduling_sent` interrupt\|when_idle\|silent beside the requested `urgency`: what was actually sent once a speaking model downgraded an INTERRUPT), `voice.push_deferred` (a push or tool result downgraded from INTERRUPT to WHEN_IDLE because the model was speaking: `kind` push\|tool_result, `name` for a tool result, `reason` always speaking, `urgency_requested`), `voice.push_timeout`, `voice.rate_limited`, `voice.recycle`, `voice.resume`, `voice.stalled`, `voice.text`, `voice.tool_call`, `voice.tool_cancelled`, `voice.tool_result` (also gains `scheduling_sent`), `voice.transcript.in`, `voice.transcript.out`, `voice.turn`, `voice.usage`
